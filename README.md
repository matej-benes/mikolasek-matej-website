# Mikolášek Matěj – oficiální web

Jednostránkový statický web hudebního interpreta Mikolášek Matěj.

## Technologie

- HTML
- CSS
- JavaScript

Web nepotřebuje Node.js, npm, Vite ani žádný build krok.

## Nasazení na Vercel

V nastavení projektu na Vercelu použij:

- **Framework Preset:** Other
- **Root Directory:** `./` (kořen repozitáře)
- **Build Command:** vypnuto / prázdné
- **Output Directory:** `.`
- **Install Command:** vypnuto / prázdné

Poté spusť Deploy. Vercel má publikovat přímo soubor `index.html`.
